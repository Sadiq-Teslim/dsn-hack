Evaluation / Reproducibility

Show the judges the system is measurable.

This page surfaces the fixture split metrics and the runbook for scaling evaluation to the Amazon Reviews subset.

What this proves

The fixture metrics are smoke tests. They prove the endpoints, ranking pipeline, rating model, and evaluation code are connected. For final scoring, the same scripts can process larger Amazon category samples.

Deployment checklist

  • Health: /health returns ok.
  • Task A: review endpoint returns rating, review, reasoning, evidence.
  • Task B: recommend endpoint returns ranked top-k items.
  • Paper: DOCX solution paper is included in docs.
